# Source provenance

This repository contains a snapshot of the current SmartSpace AI working project, including local changes.

The source checkout identifies its original remote as https://github.com/rmaduri0000/SmartSpace-AI.git and its base commit as `c627e85cfce25cb77984c063b76eb40c8672136d`.

The original checkout and history were preserved. Local environments, cached dependencies, private runtime data, agent session state, and temporary presentation renders are excluded. The built frontend files under `static/dist` are included because Flask serves them.
